# Aditya Nand — Personal Portfolio

A responsive personal portfolio website built using **HTML5 and CSS3 only**, for the HTML & CSS internship project.

## Files
- `index.html` — semantic page structure and content
- `style.css` — dark theme, layout, hover/focus states and responsive breakpoints
- `screenshots/desktop.png` — desktop preview
- `screenshots/mobile.png` — mobile preview

## Run locally
Open `index.html` in Chrome or Microsoft Edge.

## Publish with GitHub Pages
1. Create a public repository named `aditya-nand-portfolio` on GitHub.
2. Upload `index.html`, `style.css`, `README.md`, and the `screenshots` folder.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then Save.
6. After publishing, open the Pages URL shown there and test all section links.

## Project description (3–5 sentences)
This is a responsive personal portfolio website created using HTML5 and CSS3. It introduces Aditya Nand, presents his education and growing technical skill set, and highlights projects related to retail sales analytics and generative AI. The website uses semantic sections, internal navigation, CSS Grid and Flexbox, hover/focus states, and responsive media queries. It includes contact links and is designed to remain readable on desktop and mobile screens.
